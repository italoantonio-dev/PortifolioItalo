## Projetos em destaque

- **Árvore Binária de Busca:** implementação genérica em Java.
- **Algoritmos em Grafos:** Dijkstra, Bellman-Ford, Prim e Kruskal.
- **ArrayList em C++:** lista sequencial estática e interface TAD.
- **Listas Encadeadas em C++:** exercícios de manipulação de estruturas dinâmicas.
- **Café & Grão:** projeto acadêmico de desenvolvimento web.

Os links apresentados no portfólio direcionam para repositórios públicos. Projetos corporativos e materiais internos não são publicados nesta vitrine.

## Tecnologias

- HTML5
- CSS3
- JavaScript (nos projetos demonstrados)

## Executar localmente

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Abra `index.html` no navegador ou utilize uma extensão como Live Server.

Não há etapa de build para a versão estática atual.
